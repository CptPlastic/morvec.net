# morvec.net

Personal site for Tad Morvec. Static files only. There is no build step.

Plesk deploys the site by pulling the `main` branch straight into the web root of <https://morvec.net>. The homepage is `index.html` at the repository root.

## What to edit

- Words and layout: `index.html` and `css/site.css`
- The sticker-and-decal code is the `#promo` block in `index.html`. It stays up through the date in `data-until`. After that day in Oklahoma, `js/site.js` removes it.
- Social links for @tadmorvec live in one list in the footer of `index.html`. Those accounts are still being set up.
- Photos: `images/`
- Mail: tad@morvec.net
