# morvec.net

Personal site for Tad Morvec. Static files only. There is no build step.

Plesk deploys the site by pulling the `main` branch straight into the web root of <https://morvec.net>. The homepage is `index.html` at the repository root.

## What to edit

- Words and layout: `index.html` and `css/site.css`
- Notes: add a page under `notes/` and a line on `notes/index.html` (and on the homepage if it should be listed). Notes so far live as separate pages under `notes/`.
- Photos: `images/`
- Mail: tad@morvec.net
